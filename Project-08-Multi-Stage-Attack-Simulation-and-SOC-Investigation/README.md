# Project 8 – Multi-Stage Attack Simulation and SOC Investigation

## Project Overview

This project demonstrates a controlled multi-stage attack simulation in a virtual lab environment, followed by security monitoring and SOC investigation.

The project focuses on understanding how different attack activities occur across systems and how security tools can be used to collect, monitor, and investigate related events.

## Objectives

- Simulate multiple attack stages in a controlled lab environment.
- Understand endpoint and network activities during each stage.
- Collect and examine relevant security logs.
- Investigate suspicious activities using Elastic Security and other monitoring tools.
- Document findings with practical evidence and screenshots.

## Lab Environment

* Kali Linux – Attacker machine
* Windows 10 – Victim machine
* Ubuntu Server – Target server and monitoring environment

## Tools Used

- Kali Linux
- Windows PowerShell
- Sysmon
- Suricata
- Wireshark
- Elastic Security
